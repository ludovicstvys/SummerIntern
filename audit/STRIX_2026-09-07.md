# Tentative d’audit Strix — 7 septembre 2026

## Résultat

**Audit non réalisé : les requêtes Strix sont bloquées par le fournisseur du modèle.** Aucun résultat ne permet de conclure à la présence ou à l’absence de vulnérabilités.

Strix 1.5.2 a démarré deux scans avec `chatgpt/gpt-5.6-sol`, via l’abonnement ChatGPT connecté par l’utilisateur.

- `source_a00b` : statut final `failed`, mode d’authentification `subscription`, zéro requête comptabilisée comme terminée, code de sortie 1.
- `source_3687` : statut final `failed`, mode d’authentification `subscription`, environ 37.4K tokens d’entrée et 120 tokens de sortie avant blocage, zéro vulnérabilité rapportée, code de sortie 1.

Le conteneur de test n’est plus actif.

Message du fournisseur : « This content was flagged for possible cybersecurity risk. » Le service indique https://chatgpt.com/cyber pour son programme Trusted Access for Cyber. Aucun changement de modèle ou de prompt n’a été effectué pour contourner ce blocage.

## Installation et périmètre

- Sources Strix téléchargées dans `tools/strix`, commit `52b19233477a783004467c1522651eec96015e73`, exclues du suivi Git et de pytest.
- Docker installé via Homebrew/Colima ; image `ghcr.io/usestrix/strix-sandbox:1.3.0` téléchargée.
- Lanceur : `scripts/run_strix.py`. Il résout le contexte Docker pour le SDK de Strix et isole la configuration Docker des anciens helpers Docker Desktop.
- Cible : copie de 74 fichiers source comprenant les modifications locales d’authentification, sans secrets `.env`, bases réelles, listes de destinataires, historique Git ou sauvegardes.
- Périmètre local défini dans `audit/STRIX_SCOPE.md` ; aucun test du site de production ou des services tiers.
- Mode `quick`, périmètre `full`, limite de coût déclarée à Strix de 5 USD ; connexion par abonnement et aucune clé API utilisée.

## Reprise

Après résolution de l’accès cybersécurité auprès du fournisseur, relancer depuis la racine :

```sh
STRIX_LLM=chatgpt/gpt-5.6-sol python3 scripts/run_strix.py
```

La connexion ChatGPT est conservée dans le stockage privé de Strix. Ne pas inclure ses jetons dans le dépôt.
